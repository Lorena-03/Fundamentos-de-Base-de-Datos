# Unidad 6: Introducción al Lenguaje SQL

## Descripción
En esta unidad se estudian los fundamentos del **lenguaje SQL**, utilizado para crear, modificar, administrar y consultar bases de datos relacionales mediante comandos de definición y manipulación de datos.

## Temas principales
- Introducción y características del lenguaje SQL.
- **LDD (DDL):** CREATE, ALTER, DROP y TRUNCATE.
- **LMD (DML):** INSERT, UPDATE, DELETE y SELECT.
- Sintaxis y clasificación de sentencias SQL.
- Creación de tablas, claves primarias, foráneas y restricciones.
- Consultas con WHERE, ORDER BY, GROUP BY y HAVING.
- Funciones de agregación y relaciones entre tablas mediante JOIN.
- Integridad referencial y mantenimiento de datos.

##  Objetivo
Aplicar los comandos básicos de SQL para diseñar, crear, modificar y consultar bases de datos de manera correcta y eficiente.

##  Actividades

### Tarea 6.1: Sintaxis y clasificación de sentencias SQL
Investigar los comandos LDD y LMD, elaborar una tabla comparativa y documentar su sintaxis, características y aplicaciones.

### Tarea 6.2: Implementación de scripts SQL
Desarrollar scripts para crear una base de datos, insertar registros, realizar consultas y ejecutar operaciones de actualización y eliminación, verificando la integridad de los datos.

##  Resultado esperado
Comprender y aplicar correctamente las sentencias SQL para crear y administrar bases de datos relacionales, realizar consultas y garantizar la integridad de la información.
