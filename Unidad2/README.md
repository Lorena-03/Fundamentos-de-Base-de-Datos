# Unidad 2: Diseño de Bases de Datos con el Modelo E-R

## Descripción
En esta unidad se estudia y aplica el modelo Entidad-Relación (E-R) y el modelo Entidad-Relación Extendido (E-RE) para diseñar bases de datos a partir de problemáticas reales. También se realiza la transición de los diagramas E-R a diagramas de clases UML, identificando la correspondencia entre entidades, atributos y relaciones.

## Actividades

### Tarea 2.1: Modelado conceptual E-R y E-R Extendido
- Selección y descripción de un caso de estudio real.
- Identificación de entidades, atributos y reglas de negocio.
- Definición de relaciones, cardinalidades y restricciones de participación.
- Aplicación de especialización, generalización, jerarquías y agregación.
- Elaboración del diagrama E-R/E-RE mediante una herramienta CASE.

### Tarea 2.2: Transición de diagrama E-R a notación UML
- Conversión del diagrama E-R a un diagrama de clases UML.
- Correspondencia entre entidades y clases, atributos y propiedades.
- Representación de asociaciones, composición, agregación y herencia.
- Comparación entre los modelos E-R y UML.

## Objetivo de la unidad
Desarrollar habilidades para diseñar modelos conceptuales de bases de datos y representarlos mediante diagramas E-R y UML, facilitando la organización de la información y el desarrollo de sistemas orientados a objetos.
