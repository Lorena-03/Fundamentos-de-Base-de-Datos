# 📚 Fundamentos de Base de Datos

## 📖 Descripción del repositorio

Este repositorio contiene las actividades y trabajos realizados durante las seis unidades de la materia **Fundamentos de Base de Datos**.

El objetivo de esta materia es aprender cómo funcionan las bases de datos, cómo se organiza la información y cuáles son los procesos necesarios para diseñarlas y utilizarlas correctamente.

A lo largo del curso se estudian diferentes conceptos y herramientas que permiten comprender desde los fundamentos básicos hasta el uso de consultas SQL para trabajar con la información almacenada.

---

## 📂 Contenido de las unidades

### 📘 Unidad 1. Introducción a las bases de datos

En esta primera unidad se estudiaron los conceptos básicos de las bases de datos, su importancia y las diferentes áreas en las que se utilizan.

También se investigaron los distintos modelos de bases de datos, sus características y clasificaciones, así como la arquitectura de tres niveles ANSI/SPARC y el funcionamiento de los Sistemas Gestores de Bases de Datos (SGBD).

Esta unidad permitió comprender qué es una base de datos, para qué sirve y cómo ayuda a organizar y administrar grandes cantidades de información.

### 📗 Unidad 2. Diseño de bases de datos con el modelo Entidad-Relación

En esta unidad se estudió cómo diseñar una base de datos utilizando el modelo Entidad-Relación (E-R).

Se analizaron conceptos como entidades, atributos, relaciones y cardinalidades, los cuales permiten representar gráficamente la información y establecer cómo se relacionan los datos entre sí.

También se conocieron las características del modelo Entidad-Relación extendido y su utilidad para representar sistemas más complejos.

El objetivo principal fue aprender a elaborar diagramas que permitan planear la estructura de una base de datos antes de implementarla.

### 📙 Unidad 3. Modelo relacional

Durante esta unidad se estudió el modelo relacional, que permite organizar la información mediante tablas formadas por filas y columnas.

Se analizaron conceptos como relaciones, tuplas, atributos, dominios, claves primarias y claves foráneas.

También se aprendió cómo transformar un diagrama Entidad-Relación en un conjunto de tablas relacionadas, tomando en cuenta las restricciones de integridad.

Esta unidad ayudó a comprender cómo se estructura una base de datos relacional y cómo se establecen las conexiones entre sus tablas.

### 📕 Unidad 4. Normalización de bases de datos

En esta unidad se estudió el proceso de normalización, que consiste en organizar correctamente las tablas de una base de datos para evitar información repetida y problemas al almacenar, modificar o eliminar registros.

Se analizaron las dependencias funcionales y las diferentes formas normales, como la primera forma normal (1FN), segunda forma normal (2FN), tercera forma normal (3FN) y forma normal de Boyce-Codd (FNBC).

El propósito fue aprender a mejorar el diseño de las tablas para mantener la información organizada, reducir la redundancia y asegurar la integridad de los datos.

### 📒 Unidad 5. Álgebra relacional

En esta unidad se estudiaron las operaciones del álgebra relacional, utilizadas para trabajar con los datos almacenados en una base de datos relacional.

Se conocieron operaciones como selección, proyección, unión, diferencia, producto cartesiano y reuniones entre tablas.

Estas operaciones permiten obtener información específica a partir de una o varias relaciones.

Esta unidad ayudó a comprender los fundamentos teóricos de las consultas que posteriormente se realizan mediante el lenguaje SQL.

### 📓 Unidad 6. Introducción al lenguaje SQL

En la última unidad se estudió el lenguaje SQL (Structured Query Language), utilizado para crear, consultar y modificar información dentro de las bases de datos relacionales.

Se conocieron instrucciones para definir la estructura de las tablas y manipular los registros almacenados.

Entre los comandos principales se encuentran:

- **CREATE:** permite crear tablas y bases de datos.
- **INSERT:** permite agregar nuevos registros.
- **SELECT:** permite consultar información.
- **UPDATE:** permite modificar registros existentes.
- **DELETE:** permite eliminar registros.

También se estudiaron las condiciones y operaciones que permiten realizar consultas más específicas.

Esta unidad permitió relacionar los conocimientos teóricos de las unidades anteriores con el uso práctico de las bases de datos.

---

## 🎯 Objetivo general

Comprender los fundamentos de las bases de datos y desarrollar conocimientos para analizar, diseñar, organizar y administrar información mediante modelos de datos, técnicas de normalización y lenguajes de consulta.

## 📝 Conclusión

A lo largo de las seis unidades de Fundamentos de Base de Datos se adquirieron conocimientos importantes sobre la organización y administración de la información.

Primero se aprendieron los conceptos básicos y los diferentes modelos de bases de datos. Después se estudiaron las herramientas necesarias para diseñar tablas y establecer relaciones entre ellas.

También se comprendió la importancia de la normalización para evitar datos duplicados y mejorar la estructura de una base de datos.

Finalmente, se conocieron las operaciones del álgebra relacional y el lenguaje SQL, que permiten consultar y manipular información.

En general, esta materia proporcionó las bases necesarias para comprender cómo funcionan las bases de datos y cómo pueden utilizarse en el desarrollo de sistemas informáticos.
