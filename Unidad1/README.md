# Clasificación y Arquitectura de las Bases de Datos

## Descripción
En esta actividad se investigan las principales clasificaciones de las bases de datos y las arquitecturas que permiten comprender cómo se organiza y administra la información mediante un Sistema Gestor de Bases de Datos (SGBD).

## Actividades

### 1. Clasificación de las bases de datos
Investigación y elaboración de un cuadro sinóptico sobre la clasificación de las bases de datos según:
- Ubicación.
- Variabilidad de los datos.
- Modelo de datos.
- Contenido.
- Acceso o alojamiento.
- Finalidad.

### 2. Arquitectura de las bases de datos
Descripción y elaboración de dos esquemas:
- **Arquitectura de tres niveles:** externo, conceptual e interno o físico.
- **Arquitectura funcional interna del SGBD:** componentes y módulos encargados de procesar consultas, administrar transacciones, controlar la seguridad y almacenar los datos.

## Objetivo
Comprender cómo se clasifican las bases de datos, cómo se organizan sus niveles de abstracción y cómo funcionan internamente los sistemas gestores de bases de datos.
