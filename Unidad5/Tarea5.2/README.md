# Tarea 5.2: Resolución de consultas con álgebra relacional

##  Descripción
En esta actividad se aplican los conocimientos del **álgebra relacional** para desarrollar consultas sobre el esquema de base de datos del proyecto, utilizando expresiones matemáticas y operadores relacionales.

##  Temas principales
- Aplicación de operadores de álgebra relacional.
- Construcción de expresiones formales.
- Resolución de consultas de diferentes niveles de complejidad.
- Obtención y análisis de tablas intermedias.
- Interpretación de consultas en lenguaje natural.

## Objetivo
Aplicar los operadores del álgebra relacional para resolver consultas y recuperar información del esquema relacional de una base de datos.

##  Actividad realizada
Planteamiento y resolución de un catálogo de **al menos 10 consultas** basadas en el proyecto de base de datos.

Cada consulta incluye:
- Descripción del requerimiento en lenguaje natural.
- Expresión formal en álgebra relacional.
- Desglose de las tablas intermedias.
- Interpretación de los resultados obtenidos.

## ✅ Resultado esperado
Desarrollar correctamente consultas mediante expresiones de álgebra relacional, demostrando la capacidad de acceder, relacionar y recuperar información de una base de datos.
