# Unidad 4: Normalización de Bases de Datos

## Descripción
En esta unidad se estudia el proceso de **normalización de bases de datos**, cuyo objetivo es organizar correctamente la información, reducir la redundancia de datos y evitar problemas de inserción, actualización y eliminación.

## Temas principales
- Fundamentos de normalización y dependencias funcionales.
- Dependencias parciales, completas y transitivas.
- Anomalías de inserción, modificación y eliminación.
- Formas normales: 1FN, 2FN, 3FN, FNBC, 4FN y 5FN.
- Aplicación paso a paso de la normalización a un proyecto de base de datos.
- Creación de scripts SQL con estructuras normalizadas.

##  Objetivo
Aplicar las reglas de normalización para diseñar bases de datos eficientes, organizadas y con integridad de la información.

##  Actividades
- **Tarea 4.1:** Investigación de dependencias funcionales y elaboración de un mapa conceptual sobre las formas normales.
- **Tarea 4.2:** Normalización de una base de datos del proyecto, documentando cada etapa y generando el script SQL corregido.

##  Resultado esperado
Obtener un esquema de base de datos normalizado que minimice la redundancia, evite anomalías y facilite el mantenimiento de la información.
